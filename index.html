Set format reference

A set is one JSON object: title, section, minutes, and a questions array. Each question needs stem, choices, and either answer (single) or answers (multi-select and two-part).

Optional per question: topic, diff, target seconds, why for the review explanation, and stimulus for a passage or data table. Topic, difficulty, and target are what drive the pacing and error-log analysis, so keep them filled in.

LaTeX is supported anywhere text appears — stems, choices, passages, table cells, two-part headers, and explanations. Use $ ... $ or \( ... \) for inline math and $$ ... $$ or \[ ... \] for a display block. Inside a JSON file every backslash must be doubled, so \frac{3}{4} is written "$\\frac{3}{4}$". Broken math is left as plain red text rather than breaking the question.
